## Architecture

The repo has no existing code, so the patterns come from the Expo SDK 58 `default` template: routes in `src/app/`, the `@/` alias pointing to `src/`, and `expo lint`.

```
Root Stack (src/app/_layout.tsx)   loads fonts, holds the splash, light theme
├── (tabs)                         JS Tabs with a custom tabBar
│   ├── index      → Today         profile icon → router.push('/settings')
│   └── plants     → My Plants
├── scan           presentation: 'fullScreenModal', close → router.back()
└── settings       stack push, header back button
```

Scan is **not** a tab. The custom `TabBar` draws the two real tabs plus a center button that calls `router.push('/scan')`. Because of that, the tab navigator never switches to an empty "scan" tab, and Back/close returns to whichever tab you were on (spec edge case 5).

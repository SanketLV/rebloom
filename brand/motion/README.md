# Rebloom motion (Remotion)

| Composition | Size | What it is |
|---|---|---|
| `RevealWide`, `RevealSquare`, `RevealTall` | 1920×1080, 1080×1080, 1080×1920 | Logo reveal: stem rises, folded leaf opens, Lime flows in, "ebloom" grows out of the baseline |
| `Recovery` | 1080×1080 | Day 1 → Day 7: the dry, drooping r lifts and turns Lime. Also drives the brand book hero |

```bash
npm install
npm run studio   # preview and tweak timing
npm run render   # writes every video to ../kit/motion
```

How it moves: `src/mark.ts` bends the single outline of the r (each control point rotates about the leaf's base by an
amount that grows toward the tip), so there is never a seam. `src/geometry.ts` is generated by
`../source/export_motion.py` from the same drawing as the logo files; rerun it if the logo geometry changes.

Remotion is free for individuals and companies of up to 3 people; larger teams need a company license
(remotion.pro).
